# انتشار LOXX روی دامنه اصلی

سورس برای اجرای وب Next.js و API NestJS روی Node.js 22.12 یا جدیدتر آماده شده است. تغییر سورس در GitHub، به‌خودی‌خود انتشار روی VPS یا دامنه نیست. تنظیم DNS، گواهی HTTPS و سرویس اجرای دائمی باید روی میزبان انجام شود.

## اجرای نسخه جدید

در ویندوز، `START-LOXX.bat` آخرین `main` را بررسی و اجرا می‌کند. برای اجرای دستی:

```bash
npm ci
npm run setup:local
npm run build
npm start
```

`API_PORT` پیش‌فرض 4100 و `WEB_PORT` پیش‌فرض 3000 است. اگر میزبان `PORT` بدهد، فقط وب از آن استفاده می‌کند؛ پورت API جدا می‌ماند. API را فقط از شبکه داخلی یا پشت پراکسی قابل دسترسی نگه دارید.

## تنظیمات انتشار

فایل `apps/web/.env.production.example` را به `apps/web/.env.production` کپی کنید. `NEXT_PUBLIC_SITE_URL` باید URL واقعی دامنه باشد و پیش از build تنظیم شود. برای فعال‌کردن ایندکس، `NEXT_PUBLIC_ALLOW_INDEXING=true` بگذارید. تا زمانی که دامنه واقعی در محیط production صراحتاً تنظیم نشده، سایت و robots برای پیش‌نمایش noindex می‌مانند.

در `apps/api/.env`، مقادیر واقعی `WEB_ORIGIN=https://loxx.ir,https://www.loxx.ir`، `NODE_ENV=production` و یک `SESSION_SECRET` تصادفی حداقل32کاراکتری تنظیم کنید. `ADMIN_EMAIL` و `ADMIN_PASSWORD` باید اختصاصی باشند؛ رمز محلی موجود را عمومی نکنید. فایل نمونه دارای رمز قابل استفاده نیست. اتصال وب به API از `API_URL=http://127.0.0.1:4100` استفاده می‌کند.

داده SQLite و فایل‌های محیطی را خارج از انتشار سورس نگه دارید و از دیتابیس پشتیبان زمان‌بندی‌شده تهیه کنید. `setup:local` محتوای تحریریه و مدیر اولیه را به‌صورت idempotent آماده می‌کند؛ تغییرات بعدی مدیریت نباید با اجرای seed بازنویسی شوند.

## مسیر مدیریت و محتوا

- ورود: `/login`؛ مشخصات مدیر محلی در `LOCAL_LOGIN.txt` است.
- مدیریت: `/admin`؛ فقط نشست کاربر با نقش مدیر اجازه دریافت اطلاعات دارد.
- مقاله‌ها: ایجاد، ذخیره پیش‌نویس، انتشار، ویرایش متن Markdown و فیلدهای سئو.
- درخواست‌ها: مشاهده مشاوره‌ها و برآوردها، جست‌وجو و تغییر وضعیت.
- بلاگ از API می‌خواند؛ حذف انتشار مقاله باید آن را از فهرست عمومی خارج کند.

پس از انتشار، صفحه اصلی، یک مقاله، یک صفحه خدمت، یک نمونه‌کار، ثبت فرم و ورود مدیریت را روی HTTPS بررسی کنید. سپس sitemap را در Google Search Console ثبت کنید. راهبرد محتوا و محدودیت‌های رتبه‌گیری در `seo-keyword-strategy.md` آمده است.

## مواردی که باید قبل از انتشار تأیید شوند

بازه‌های قیمت، بودجه‌های پیشنهادی اولیه‌اند؛ بازبینی تجاری لازم دارند. پروژه مهراد کویر با وضعیت انتظار انتشار معرفی شده است. نام و عکس شخصیت‌های تیم ساختگی و برچسب‌خورده‌اند؛ برای معرفی اعضای واقعی، اطلاعات و تصاویر مجاز را جایگزین کنید. ادعاهای بدون سند، نظرات ساختگی، شمارنده مشتری یا تضمین رتبه در سایت وجود ندارد.
