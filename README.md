# LOXX — Digital Product Studio

لندینگ فارسی استودیو LOXX بر اساس کانسپت نئونی و راهنمای هویت بصری: منظره تمام‌عرض و نشان X، خدمات، گالری بزرگ با فیلتر و جزئیات پروژه، مسیر همکاری تعاملی، معرفی تصویری استودیو، انتخاب نوع پروژه و اولویت‌ها، پرسش‌های متداول، یادداشت‌ها، فرم درخواست و فوتر کامل.

انتخاب‌های بخش پیشنهاد پروژه به‌صورت مستقیم به فرم برآورد منتقل می‌شوند. فرم به API و دیتابیس وصل است. صفحات وبلاگ، متن کامل یادداشت‌ها و ورود/حساب کاربری نیز زبان بصری همین سایت را ادامه می‌دهند.

### اجرا در ویندوز

1. Node.js نسخه 22.12 یا جدیدتر و Git نصب باشند؛ دسترسی به GitHub برای بررسی آخرین نسخه لازم است.
2. فایل‌های مخزن یا ZIP را در `D:\loxx\website` قرار دهید.
3. پنجره اجرای قبلی سایت را ببندید و فایل `START-LOXX.bat` را اجرا کنید. آخرین نسخه `origin/main` دریافت و تطبیق داده می‌شود؛ سپس وابستگی‌ها و دیتابیس محلی آماده می‌شوند.
4. سایت در `http://localhost:3000` و API در `http://localhost:4100/api/health` اجرا می‌شود.

اگر فقط لانچر را دانلود کرده‌اید، مخزن را در `D:\loxx\website` دریافت می‌کند. اگر لانچر کنار `package.json` باشد، همان پوشه پروژه انتخاب می‌شود. برای تعیین مسیر دیگر، متغیر محیطی `LOXX_PROJECT_DIR` را تنظیم کنید.

لانچر برای نصب‌های ZIP هم کار می‌کند: ابتدا از سورس و داده‌های محلی در پوشه هم‌سطح `.loxx-launcher-website/backups` پشتیبان می‌گیرد و سپس Git را راه می‌اندازد. در مخزن موجود، تغییرات ثبت‌نشده با `git stash` و کامیت‌های قبلی با شاخه‌های `loxx-backup-*` نگهداری می‌شوند. تغییرات محلی خودکار روی نسخه جدید اعمال نمی‌شوند؛ برای بازیابی، `git stash list` و `git stash apply` یا شاخه پشتیبان را بررسی کنید.

شناسه کامیت محلی و `origin/main` باید در خروجی با `[MATCH]` یکسان باشند. اگر دریافت نسخه جدید شکست بخورد، سورس ناسازگار باشد یا پورت‌های 3000 و 4100 اشغال باشند، اجرا متوقف می‌شود. لاگ و مشخصات نسخه در پوشه هم‌سطح `.loxx-launcher-website` قرار می‌گیرند. نصب وابستگی‌ها از `package-lock.json` با `npm ci` انجام می‌شود و در صورت تغییر ورودی‌ها تکرار خواهد شد. کش تولیدشده Next.js قبل از اجرا پاک می‌شود؛ مرورگر پس از پاسخ‌دادن سایت و API باز می‌شود.

مشخصات ورود مدیر محلی در فایل خصوصی `LOCAL_LOGIN.txt` ساخته می‌شود. این فایل، دیتابیس و فایل‌های محیطی وارد Git نمی‌شوند. برای توقف سرورها `Ctrl+C` بزنید.

### توسعه

```bash
npm ci
npm run setup:local
npm run dev
```

```bash
npm test
npm run typecheck
npm run build
npm start
```

ساختار: `apps/web` رابط Next.js، `apps/api` سرویس NestJS و Prisma با SQLite محلی، `tools/setup-local.mjs` راه‌اندازی دیتابیس و رمز تصادفی مدیر. API از طریق مسیر هم‌مبدأ `/api` پروکسی می‌شود. برای اجرای عمومی، دامنه واقعی را در `WEB_ORIGIN` و `NEXT_PUBLIC_SITE_URL` تنظیم کنید و یک `SESSION_SECRET` تصادفی اختصاصی داشته باشید.

تصاویر WebP برای همین کانسپت تولید و فشرده شده‌اند. تصویر دنیای استودیو مفهومی است و عکس دفتر واقعی نیست. نمونه‌کارها به‌عنوان کانسپت طراحی مشخص شده‌اند؛ آمار، مشتری یا رضایت ساختگی منتشر نشده است. رنگ پایه برند `#00D4A7` و رنگ نورپردازی نئونی `#00E6DD` است. فونت فارسی Vazirmatn به‌صورت محلی بسته‌بندی شده؛ برای استفاده از IRANSansX برندبوک، فایل دارای مجوز آن را اضافه کنید. مشخصات و پرامپت تصاویر جدید در [visual-assets.md](docs/visual-assets.md) ثبت شده است.

این پروژه برای اجرا به وب‌سرور نیاز دارد؛ فایل TSX با دوبارکلیک در مرورگر اجرا نمی‌شود. میزبانی عمومی در این تغییر فعال نشده است.
